## Features

- **Subscription import** — VLESS / VMess / Trojan, files and links
- **Smart server selection** — ping, countries, blocked servers, auto-switch
- **VPN modes** — rules, global, direct; split-tunnel per app
- **Routing rules** — add, edit and organize rules in a few clicks
- **Backup** — export/import servers, rules and settings

## Installation

1. Click **Install** above
2. Download `PawLink-Setup.exe` from the release page
3. Run the installer as administrator (required for TUN mode)

### Requirements

- Windows 10 / 11 (64-bit)
- Python 3.11+ (backend runtime after install)
- Administrator rights — for **Rules** mode (TUN)
