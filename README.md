## Возможности

- **Импорт подписок** — VLESS / VMess / Trojan, файлы и ссылки
- **Умный подбор сервера** — пинг, страны, запрещённые серверы, автопереключение
- **Режимы VPN** — правила, глобальный, без VPN; split-tunnel для приложений
- **Правила маршрутизации** — добавление, редактирование и группировка в пару кликов
- **Резервная копия** — экспорт/импорт серверов, правил и настроек

## Установка

1. Нажмите **«Установить»** выше
2. Скачайте `PawLink-Setup.exe` на странице релиза
3. Запустите установщик от администратора (нужен для режима TUN)

### Системные требования

- Windows 10 / 11 (64-bit)
- Python 3.11+ (для работы backend после установки)
- Права администратора — для режима «Правила» (TUN)
